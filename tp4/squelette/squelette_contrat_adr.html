Squelette technique et contrat d'API — Gestion des stages

Dépôt : github.com/aspic36/tp-projet-info2  ·  PHP 8.3.33 · MySQL 8.4.3  ·  Date : 18 / 11 / 2026

Le socle technique met en place l'arborescence, la configuration locale, la connexion PDO et le premier point d'entrée. Aucun secret n'est versionné et chaque couche a une responsabilité unique : les contrôleurs traduisent HTTP, les services portent les règles métier, les dépôts contiennent le SQL.

3. Connexion PDO avec exceptions

final class Database
{
    private static ?PDO $pdo = null;

    public static function pdo(): PDO
    {
        if (self::$pdo instanceof PDO) {
            return self::$pdo;
        }
        $db = Config::get('db');                 // valeurs issues de .env
        $dsn = sprintf('mysql:host=%s;port=%d;dbname=%s;charset=%s',
            $db['host'], $db['port'], $db['name'], $db['charset']);

        self::$pdo = new PDO($dsn, $db['user'], $db['pass'], [
            PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
            PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
            PDO::ATTR_EMULATE_PREPARES   => false,
        ]);
        return self::$pdo;
    }
}

6. ADR-001 — Monolithe modulaire PHP sans framework

DécisionMonolithe modulaire PHP 8, front controller unique, PDO, couches Controllers → Services → Repositories, sans framework ni Composer.
ContexteProjet universitaire de 2 h par séance, postes Windows sans Composer garanti, installation exigée sur un second poste à partir du seul dépôt.
ConséquencesInstallation réduite à PHP et MySQL ; autoload, routeur et validation écrits à la main (environ 400 lignes testables) ; SQL explicite en requêtes préparées ; couches remplaçables indépendamment.
AlternativesLaravel (écarté : installation lourde, hors du temps disponible) ; SQLite (écarté : le cours impose MySQL) ; micro-services (surdimensionné).
