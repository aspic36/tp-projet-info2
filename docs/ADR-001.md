# ADR-001 — Monolithe modulaire PHP sans framework

- **Date** : 18 novembre 2026
- **Statut** : acceptée
- **Décision** : construire l'application comme un monolithe modulaire en PHP 8,
  avec un front controller unique, PDO pour la base et des couches
  `Controllers → Services → Repositories`. Aucun framework ni dépendance Composer
  n'est utilisé.
- **Contexte** : projet universitaire de 2 h par séance, postes Windows sans
  Composer garanti, besoin d'installer l'application sur un second poste à partir
  du seul dépôt.
- **Conséquences** : installation réduite à PHP et MySQL ; l'autoload PSR-4, le
  routeur et la validation sont écrits à la main (environ 400 lignes, testables) ;
  pas de ORM, donc SQL explicite en requêtes préparées ; la séparation des couches
  reste vérifiable et permet de remplacer un dépôt par un double de test.
- **Alternatives écartées** : Laravel (installation lourde, courbe d'apprentissage
  hors du temps disponible), SQLite (écart avec le cours qui impose MySQL),
  architecture micro-services (surdimensionnée pour un monôme étudiant).
