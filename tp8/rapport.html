3. Revue de code — quatre remarques classées

Mineure fonctionnelle — paramètre nommé répété dans la recherche (corrigé)

Dans DemandeRepository::search(), la recherche multi-colonnes réutilisait le même marqueur :q quatre fois :

// AVANT — provoque SQLSTATE[HY093]
$where[] = '(u.nom LIKE :q OR u.prenom LIKE :q
             OR e.matricule LIKE :q
             OR en.raison_sociale LIKE :q)';
$params[':q'] = '%' . $q . '%';
// APRÈS — un marqueur par occurrence
$where[] = '(u.nom LIKE :q_nom
  OR u.prenom LIKE :q_prenom
  OR e.matricule LIKE :q_matricule
  OR en.raison_sociale LIKE :q_entreprise)';
$params[':q_nom'] = $motif; /* … */

Avec les requêtes réellement préparées (EMULATE_PREPARES = false), MySQL refuse un marqueur répété : la recherche renvoyait 500. Détecté par S-07 et S-08. La correction donne un marqueur distinct par occurrence ; la valeur reste liée, jamais concaténée.

Majeure — jeton CSRF périmé après déconnexion (corrigé)

La déconnexion détruit la session, donc le jeton CSRF. Le frontend conservait néanmoins l'ancien jeton en mémoire : la première écriture après une reconnexion était refusée en 403. Correctif : rafraichirJeton() rappelle GET /api/session après chaque connexion et chaque déconnexion. Le contrôle S-15 vérifie l'écriture avec le jeton en mémoire après connexion ; il ne rejoue pas de déconnexion préalable.

Majeure — écrans masqués visibles à cause de display:flex (corrigé)

L'attribut hidden a une priorité plus faible qu'une règle de classe : les blocs en display: flex restaient affichés alors qu'ils portaient hidden (révélation d'actions réservées à d'autres rôles, donc défaut de confidentialité au minimum visuel). Correctif global :

[hidden] { display: none !important; }

Le contrôle serveur reste la vraie barrière (S-02 à S-05) : le correctif CSS n'est qu'une mesure de cohérence d'affichage.

Mineure — pas de limitation des tentatives de connexion (acceptée, v2)

Rien ne freine une attaque par force brute sur POST /api/session. La mesure est identifiée mais reportée : elle demande un stockage partagé (compteur par IP et par compte) et un temps de réponse constant, hors du périmètre de cette version. Elle est consignée dans la dette technique du README.md et reportée à la version 2.
