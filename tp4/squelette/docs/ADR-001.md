# ADR-001 — Monolithe modulaire PHP sans framework

- **Contexte** : équipe de trois ou quatre étudiants, 25 h, postes Windows sans Composer garanti, installation exigée sur un second poste à partir du seul dépôt.
- **Décision** : monolithe modulaire PHP 8 avec front controller, PDO et couches `Controllers → Services → Repositories` ; le SQL reste dans les dépôts, sans framework ni ORM.
- **Conséquences positives** : démarrage rapide, peu de dépendances, couches remplaçables par des doubles de test.
- **Conséquences négatives** : routeur et validation écrits à la main, couplage plus fort entre modules.
- **Alternatives écartées** : Laravel trop lourd pour 25 h, SQLite écarté par le cours, micro-services surdimensionnés pour un projet étudiant.
